# Contributing

Use a feature branch and a reviewable pull request. Run `npm ci --ignore-scripts`, `npm test`, `npm run demo`, and `npm run benchmark` on Node 22 or newer. Add synthetic regression cases for changes to matching or financial arithmetic. Keep dependencies and changes focused.

Do not submit private data. Preserve signed integer milliunits, duplicate multiplicity, explicit uncertainty, bounded searches, and the absence of write tools in the analysis server. Test permission enforcement in the upstream write adapter separately before claiming a restricted-write workflow is supported.

Before proposing a new feature, identify the user's question, authoritative data, deterministic calculation, evidence needed for a recommendation, and any authorized side effect. Browser UI customization alone is outside this project's scope.
